
# Smart Study Planner 📚

## About the Project
Smart Study Planner is a simple web application developed using Python and Streamlit. It helps students organize their study tasks, set deadlines and track their study progress.

## Features
- Add study tasks and subjects.
- Set deadlines for tasks.
- Mark tasks as completed.
- View completed task count.
- Track study progress.

## Technologies Used
- Python
- Streamlit
- Pandas

## How to Run

1. Install Python.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the application:

   streamlit run app.py

4. Open the local URL in your browser.
